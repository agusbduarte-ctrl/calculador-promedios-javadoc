## Actividad: Depuración, Git y Javadoc

Vamos a trabajar sobre un proyecto Java que contiene errores intencionales.

### Actividad

1. Crear un **Fork** del repositorio y clonarlo en la computadora.
2. Analizar, **corregir y probar** el proyecto.
3. Documentar el código utilizando **Javadoc**.
4. Realizar los commits y `push` correspondientes.
5. Crear un **Pull Request** hacia el repositorio del profesor.

**Importante:** cada estudiante debe trabajar sobre su propio Fork. No deben modificar directamente el repositorio del profesor.

Repositorio:

[calculador-promedios-javadoc](https://github.com/cerdanva/calculador-promedios-javadoc?utm_source=chatgpt.com)

### Entrega

En Classroom deberán entregar **el enlace a su Pull Request**.

Antes de comenzar, **lean atentamente el README del repositorio**, donde encontrarán la consigna completa, los pasos y los criterios de evaluación.
